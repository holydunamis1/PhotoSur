# PhotoSur

Remove photo backgrounds instantly. Free, with ads. Remove ads with a one-time $14.99 purchase.

## Repo layout

```
/
├── .github/workflows/    # Android CI (GitHub Actions)
├── codemagic.yaml         # iOS CI (Codemagic)
├── app/                   # Flutter project root
│   ├── lib/
│   │   ├── core/          # Models, providers, services — no OS-branching logic
│   │   ├── platform/      # dart:io / Platform.isIOS branching lives here only

│   │   ├── screens/       # Full-screen routes

├── website/                # Landing, privacy, support pages (Cloudflare Pages)
└── store_submission/       # ASO metadata, data-safety docs, screenshot strategy
```

## Build (CI only — this project has no local development toolchain)

This project is built entirely through CI. There is no expectation of
running `flutter run` locally.

**Android**: push to `main` or trigger `.github/workflows/
build_and_deploy.yml` manually (`workflow_dispatch`). Produces a
release AAB, release APK, and debug APK as workflow artifacts.

**iOS**: trigger the `ios-workflow` in Codemagic manually. Produces a
release IPA, uploaded to TestFlight automatically.

Both pipelines run `dart run build_runner build` (generates `.freezed.dart`/
`.g.dart` files and, via `generate: true` in `pubspec.yaml`, the l10n
`AppLocalizations` class) and a CI gate that fails the build if
`throw UnimplementedError` appears anywhere in `lib/`.

## Architecture

- **State management**: `ValueNotifier` + `ValueListenableBuilder`
  only. `package:provider` is used strictly for dependency injection
  (`Provider<T>.value` + `Provider.of<T>(context, listen: false)`) —
  never `Consumer`, `context.watch()`, or `context.read()`.
- **Models**: `freezed` (^3.2.5 — note the `abstract class` syntax
  required by freezed 3.x, a breaking change from 2.x).
- **ML segmentation**: Path B default — `tflite_flutter` + a bundled
  U2-Net model, cross-platform. See `segmentation_service.dart` for
  the still-open product-photo quality verification requirement.
- **Monetization**: ad-supported free tier (Google AdMob) + one-time $14.99 ad-removal purchase (non-consumable, product ID `com.zdmgold.photosur.adfree`)
  IAP to remove ads, with zero feature gating either way. IAP
  validation is on-device only (no backend) — see `iap_service.dart`
  for the reasoning.
- **Zero backend**: no server, no accounts. All data is local to the
  device (sqflite + SharedPreferences).

## Known open items

- **Segmentation quality against real product photos is unverified.**
  This requires a physical device and real photos, and could not be
  tested during the build-planning or code-generation process. See
  `segmentation_service.dart`'s doc comment and the build plan's
  Section 14 checklist.
- **Localization**: v1 ships English-only, but the app is fully wired
  to `AppLocalizations`/ARB-based localization (not hardcoded strings)
  so a second language is a translation task, not a re-engineering one.
- Several dependencies were added beyond the original build plan
  during implementation (`permission_handler`, `flutter_image_compress`,
  `crop_your_image`, `url_launcher`, `cross_file`) — each is documented
  inline in `pubspec.yaml` with the specific gap it closes.

## Contributing

This is currently a solo project built phase-by-phase against a
detailed build plan (not included in this repo's public files). If
you're picking this up: check `pubspec.yaml`'s inline comments before
bumping any dependency — several have version-specific gotchas
(`intl` is pinned by `flutter_localizations`'s SDK requirement and
must not be bumped independently; `freezed` 3.x uses different syntax
than 2.x).
